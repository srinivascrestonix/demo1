# Demo1 Project

A modern full-stack portfolio application featuring a React frontend and a Node.js backend.

## Project Structure

- **frontend/**: React/Vite application with Tailwind CSS and animations.
- **backend/**: Express.js server managing the API and database.

## Prerequisites

- Node.js (v18 or higher)
- npm or yarn

## Installation & Setup

### 1. Backend Setup
```bash
cd backend
npm install
# Configure your .env file
npm start
```

### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```

## Technologies Used

- **Frontend**: React, Vite, GSAP, Lenis, Tailwind CSS
- **Backend**: Node.js, Express, Turso (SQLite)
- **Deployment**: Vercel (Frontend), Railway (Backend)
